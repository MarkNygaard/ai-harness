Two integrations, connected on **Settings → Integrations**. They do different
jobs and only one of them is required.

<Cards>
  <Card title="GitHub" href="/docs/integrations/github">
    The token every run needs to clone, push and open pull requests. Required.
  </Card>
  <Card title="Linear" href="/docs/integrations/linear">
    Delegate an issue and the harness picks it up, moves it through your status
    map, and reports back in the issue thread. Optional, and the route most
    teams should take.
  </Card>
</Cards>

## The difference between these and subscriptions

[Subscriptions](/docs/operating/subscriptions) are the accounts your **agents**
run on: Claude, ChatGPT, Kimi, Cursor. They decide what the models cost and who
they bill.

Integrations are the systems the **harness** talks to. GitHub is where the code
lives and where the pull request lands. Linear is where the work is described
and where progress is reported.

One other difference worth knowing: GitHub is the only credential anywhere in
the harness that can be set per project. Everything else is global. See
[per project, with a global fallback](/docs/integrations/github#per-project-with-a-global-fallback).
